# Acode Express Helper

Plugin for Acode (v1.12.6) that provides:
- Autocomplete for Express API and common backend packages
- Package name suggestions inside require/import
- Useful route/middleware/snippet templates

Install:
1. Zip the plugin folder and rename extension to `.acode-plugin` OR place files in repo and download.
2. In Acode: Settings → Add-ons → Install Local Plugin → select the `.acode-plugin` file.

Files added by this plugin:
- plugin.json (manifest)
- main.js (autocomplete provider)
- snippets.json (structured snippets)

If you want additional packages/snippets added, tell me which ones and I will extend the plugin.
